# 🍊 Fanta - Landing Page

Landing page de produto com visual vibrante e **animações de rolagem**, desenvolvida com HTML, CSS e JavaScript puro e a biblioteca GSAP.

> ℹ️ **Projeto de estudo, sem fins comerciais.** Fanta, Coca-Cola, Pepsi e as demais marcas e imagens pertencem aos seus respectivos donos. Este projeto foi criado apenas para praticar front-end.

---

## ✨ O que tem na página

- **Navbar** com logo e menu (Home, Produtos, Loja e Contatos)
- **Hero** com o título em destaque e imagens da lata, de laranjas e de folhas sobrepostas
- **Seção de sabor** com um blob em SVG inline ao lado de um bloco de texto
- **Cards de produtos** com botão "Comprar agora"
- **Animações de rolagem** usando GSAP e ScrollTrigger

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/) 3.12.2
- [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) (plugin do GSAP)

---

## 🚀 Como rodar o projeto

Não precisa instalar nada.

```bash
# 1. Clone o repositório
git clone https://github.com/CleitonB3/Fanta.git

# 2. Entre na pasta
cd Fanta
```

Depois, abra o arquivo `index.html` no navegador. Se preferir, use a extensão **Live Server** do VS Code para atualizar a página automaticamente a cada alteração.

> O GSAP é carregado por CDN, então é necessária conexão com a internet.
